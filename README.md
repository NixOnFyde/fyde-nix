# fyde-nix - NixOS for the FydeTab Duo

Nix flake for support for the [FydeTab Duo](https://fydetabduo.com/) - Fyde Innovation's Open-source RK3588S hackable tablet. The aim of this flake is feature parity with the official Arch/Omarchy images, including but not limited to:

- [x] GPU acceleration (Mali G610 through Panthor);
- [x] deep suspend/resume;
- [x] WiFi;
- [x] bluetooth;
- [x] touch / stylus;
- [x] sensors;
- [x] USB-C DisplayPort;
- [x] and the HiDPI portrait panel.

> [!TIP]
